# Contributing to Shopee Scraper Extension

Thank you for considering contributing to **Shopee Scraper Extension**! We welcome contributions, bug reports, and feature suggestions from the open-source community.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs
If you encounter a bug or unexpected behavior:
- Open an issue on [GitHub Issues](https://github.com/Tnembull/shopee-scraper-extension/issues).
- Describe the bug clearly, including steps to reproduce and any error messages from the Chrome Developer Console.

### 2. Suggesting Features
Enhancements and new feature ideas are welcome:
- Open a feature request issue.
- Describe the feature and why it would be beneficial.

### 3. Submitting Pull Requests (PRs)
1. Fork the repository on GitHub.
2. Create a new topic branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. Make your changes and test the Chrome Extension using `chrome://extensions` in **Developer mode**.
4. Ensure JavaScript syntax is clean:
   ```bash
   node -c background.js content.js popup.js
   ```
5. Commit your changes with a clear commit message:
   ```bash
   git commit -m "feat: add my new feature"
   ```
6. Push to your branch and open a Pull Request against the `main` branch.
